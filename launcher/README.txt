OpenTzar Launcher 1.0 (Windows 10/11 x64, .NET Framework 4.8)
Rozpakuj ZIP i uruchom OpenTzarLauncher.exe. Kliknij AKTUALIZUJ / ZAINSTALUJ, potem GRAJ.
Gra znajduje się w %LOCALAPPDATA%\OpenTzar\Player\Game. Wymaga oryginalnej instalacji Tzara; launcher jej nie modyfikuje. Gra działa offline po pierwszej instalacji.
Aktualizacje przyrostowe są dostępne z poprzedniej wersji kanału, w pozostałych przypadkach pobierana jest pełna paczka. Poprzednia instalacja jest zachowana w Game.previous. Napraw grę pobiera pełną paczkę. Automatyczna aktualizacja samego launchera nie jest jeszcze dostępna.
